# Self-hosted web fonts

`index.html` loads these font files directly; no Google Fonts requests are needed at runtime.

| File | Family | Style / weights | Licence |
| --- | --- | --- | --- |
| `montserrat-latin-variable.woff2` | Montserrat | Normal, 100–900 | `Montserrat-OFL.txt` |
| `caveat-latin-variable.woff2` | Caveat | Normal, 400–700 | `Caveat-OFL.txt` |

These are unmodified Latin-subset variable WOFF2 files served by Google Fonts. They cover the site's English text; symbols and emoji may use system fallback fonts. Additional scripts or true italic styles require separate font assets.
